## 1. Кліпи й порядок показу

Усі кліпи — з нашого **train / val** (не з тесту), без вшитих підписів і водяних знаків. Відео — справжній прогін
конвеєра (режим A, ті самі ваги й пороги, що в експерименті). На кадрі розмиті обличчя, учасники інциденту —
зеленим, сторонні — сірим, зброя — червоним. Зверху — стан автомата, ризик вікна й час; праворуч — текст
повідомлення в Telegram.

| № | Файл | Звідки | Що показує | Тривалість |
|---|---|---|---|---|
| 1 | `results/demo/1_fight_h264.mp4` | RWF-2000, наш train: `JwTPruSFTjk` — 4 сегменти однієї камери (спокій → бійка → бійка → спокій) | Бійка в залі кафе: ризик росте, «увага» → «тривога» (≈ 7 с від початку бійки), одне повідомлення, «затихання»; закриття — з кінцем відео | ≈ 22 с |

Камера Севільї має власний напис (назва камери й годинник). Його розмито лише у вихідному відео (`--hide`), а
конвеєр бачить оригінальний кадр, тож поведінка та сама, що в експерименті.

Перебудувати відео (≈ 7 хв на CPU): `bash results/demo/make_demo.sh`. Скрипт робить те саме, що ці команди:

```bash
R=data/raw/rwf2000/train
uv run sentinel demo --no-telegram --label "Зал кафе" --out results/demo/1_fight.mp4 --source \
  $R/NonFight/JwTPruSFTjk_1.avi $R/Fight/JwTPruSFTjk_0.avi $R/Fight/JwTPruSFTjk_1.avi $R/NonFight/JwTPruSFTjk_0.avi
uv run sentinel demo --no-telegram --label "Хол" --out results/demo/2_weapon.mp4 \
  --sevilla Cam5-From09-47-49To09-48-30_x264 --hide 0 0 0.09 0.07 --hide 0.37 0.92 0.63 0.99
uv run sentinel demo --no-telegram --label "Торговий центр" --out results/demo/3_calm.mp4 --source \
  $R/NonFight/oUqxGhTe_0.avi $R/NonFight/oUqxGhTe_0.avi $R/NonFight/oUqxGhTe_0.avi
# H.264 для будь-якого програвача: ffmpeg -i results/demo/1_fight.mp4 -c:v libx264 -pix_fmt yuv420p results/demo/1_fight_h264.mp4
```

Без `--no-telegram` ті самі прогони надсилають справжні повідомлення в бот із `.env`. На репетиції це дає
скриншоти з телефону.

## 3. Якщо щось не спрацює

| Що сталося | Що робимо |
|---|---|
| Вебкамера не відкривається (`camera / stream unavailable`) | Показати відео 1–3. Живий запуск замінити прогоном з файлу в темпі камери: `uv run sentinel run --source results/demo/1_fight_h264.mp4 --paced` — повідомлення прийде в бот так само |
| Немає інтернету / Telegram не відповідає | Повідомлення й так видно у відео (праворуч) і в консолі. Показати скриншоти з репетиції (`results/demo/screens/`, якщо зроблено) |
| `/mode B` або каскад: «B недоступний» чи відповідей немає | Пояснити: безкоштовний ліміт Groq, у live B ніколи не блокує конвеєр — вікна лишаються за A. Повернути `/mode A` |
| Живцем нічого не спрацьовує (одна людина перед камерою — це не бійка) | Так і має бути: спокій. Показати відео 1 і 2 |
| Ноутбук гальмує (RTF > 1, кадри пропускаються) | Перевірити, що від мережі й профіль `performance`; закрити Docker-тести інших проєктів |
| Програвач не відкриває `.mp4` | Брати `*_h264.mp4` (H.264), відкривати через `mpv` або браузер |

## 4. Живий запуск: команда й чек-лист (не виконувалось без Дмитра)

**Команда (хост):**

```bash
uv run sentinel run --source 0          # вебкамера; Ctrl+C — зупинити
```

**Або в Docker (той самий образ, що в протоколі випробувань):**

```bash
docker run --rm --user "$(id -u):$(id -g)" --env-file .env --device /dev/video0 --group-add video \
  -v "$PWD/weights:/app/weights:ro" -v "$PWD/results:/app/results" sentinel:dev run --source 0
```

**Чек-лист за 15 хв до показу:**

- [ ] Ноутбук **від мережі**, профіль `performance` (`powerprofilesctl get`), **кришка відкрита**.
- [ ] Docker-тести інших проєктів зупинені; `uptime` — load average < 2.
- [ ] `.env`: `TELEGRAM_TOKEN`, `TELEGRAM_CHAT_IDS` заповнені; для `/mode B` — `GROQ_API_KEY`.
- [ ] Прогін B на val (`sentinel-b`) не з'їдає добовий ліміт Groq у день показу: якщо він ще йде — зупинити
      на час показу `systemctl --user stop sentinel-b.timer sentinel-b.service`, потім запустити знову (`start`).
- [ ] Вебкамера є: `ls /dev/video0`; шторка відкрита; світло спереду.
- [ ] Бот відповідає: надіслати `/status` (за ~1 с має прийти «Режим: A · RTF … · … кадр/с …»).
- [ ] Звук телефону ввімкнено (повідомлення має бути чути) або телефон виведено на екран.
- [ ] Відео 1–3 (`*_h264.mp4`) відкриваються в програвачі; вкладки зі слайдами відкриті.
- [ ] Після показу: `/mode A`, Ctrl+C у терміналі.
