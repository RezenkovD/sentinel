## Примітки (додано вручну)

- **Що це:** перевірка перед заморозкою сприйняття (завдання сесії 03, крок 2) — швидке вилучення 200 кліпів
  нашого train (100 Fight + 100 NonFight, seed 2026), OpenVINO. Відтворення:
  `uv run sentinel eval extract --dataset rwf2000 --parts train --per-class 100 --backend openvino`, далі
  `uv run sentinel eval feature-auc --dataset rwf2000 --parts train`.
- **Сильніші за все** — рух у кадрі й рух людей: `motion_area` 0,75, `crowd_motion` 0,73, `motion_energy` 0,73,
  `max_speed` 0,70, `max_pose_motion` 0,67, `max_person_motion` 0,66. Нові ознаки v3 дали чотири з шести
  найсильніших.
- **Згладжене відносне прискорення рук** — 0,55 (у v2 сирі різниці давали 0,49, тобто шум); швидкість рук — 0,59.
- **≈ 0,5 за побудовою на RWF:** `zone_prior` (у RWF одна зона — ознака стала), `weapon_held` / `weapon_visible`
  (зброї в RWF немає) — потрібні для розгортання й сценарію «зброя», не для бійок.
- **≈ 0,5 без змістовного пояснення:** `facing_close` 0,51 — «обличчям одне до одного» за зсувом носа з 2D-скелета
  на ракурсах CCTV ненадійне. **Кандидат на вилучення.**
- **Слабко обернені:** `min_distance_h` 0,47, `max_contact_s` 0,44 — спокійні групи стоять ближче й довше, ніж
  б'ються; логістична регресія врахує знак.
- Вікон без людей: Fight 15 %, NonFight 26 %. Для них A за SPEC §5 повертає нульовий ризик, тож рух у пікселях A
  там не допомагає; `baseline_motion` бачить і такі вікна.
