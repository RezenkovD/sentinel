## Примітки (додано вручну)

- **Бекенд — OpenVINO 2026.4 на CPU** (`uv run --with openvino`, не залежність проєкту), FP32, `dynamic=True`, для всіх
  трьох моделей: YOLO26n, YOLO26n-pose, WeaponShield YOLOv8s. Кліпи й варіанти ті самі, що в
  `bench_pipeline_2026-09-29.md` (PyTorch).
- **Умови гірші, ніж під час заміру PyTorch:** від мережі, `performance`, але load average 8–12 (PyCharm, інші
  процеси). Тому порівняння з PyTorch ненадійне. Для 480 OpenVINO вийшов навіть повільнішим, хоча в тихому
  замірі 28.09 він вигравав 6–18 %.
- **Висновок.** На OpenVINO кращі варіанти — `640:2` (RTF@10 = 0,88) і `crops320:2` (0,91), але межу 0,8 не
  проходить жоден. У темпі камери відставання не накопичується (затримка p95 — 150–250 мс), проте частота
  аналізу падає до 8,3–9,3 кадру/с. Для рекомендованих варіантів окремо заміряно 8 кадрів/с —
  `bench_pipeline_openvino_fps8_2026-09-29.md`.
