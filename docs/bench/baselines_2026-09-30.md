## baseline_motion (енергія руху в кадрі з порогом)

- Поріг τ = 2,140 рівнів сірого на найбільшій енергії вікна епізоду (F1 на val).
- Val: AUC епізодів 0,743, AUC вікон 0,757, F1 0,722; TP 131, FP 72, FN 29, TN 88.

## Примітки (додано вручну)

- **Відтворення:** `uv run sentinel eval baselines` (кеш: Севілья Cam1 + Cam5, наш train і val RWF).
- **baseline_weapon.** Критерій τ завдання не задає. Рядок таблиці з обмеженням правила зброї (≤ 1 % NonFight з
  тривогою) дає τ = 0,75 і **нульову** повноту — базовий метод, що ніколи не спрацьовує, для порівняння непридатний.
  Найкращий F1 вікон на спільному dev (вікна Севільї + усі вікна train RWF як негативи) — 0,185 при τ = 0,10 (і 50 %
  спокійних кліпів з тривогою). Тому τ = **0,30** — робоча точка детектора з сесії 02 (≤ 2 % хибних кадрів Севільї),
  той самий поріг, що й в описі сцени. Рішення — за Дмитром.
- **baseline_motion.** τ = 2,14 рівня сірого (найбільша енергія руху вікна епізоду, F1 на нашому val). Для
  порівняння, A v1 на тому самому val: AUC епізодів 0,849 проти 0,743, F1 0,790 проти 0,722.
